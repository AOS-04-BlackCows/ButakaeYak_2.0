## 1. 프로젝트 소개
### 복잡한 약물 관리, 여러 앱을 사용하느라 불편하셨나요?
### **‘부탁해약’** 하나면 모든 약물 관리가 손쉽게 해결됩니다!!
[다운로드 링크](https://play.google.com/store/apps/details?id=com.blackcows.butakaeyak&pli=1) 
### 카메라로 처방전 인식, 약 등록은 간편하게!!

- 처방전을 카메라로 찍기만 하면 자동으로 약 정보를 등록할 수 있습니다.
- 더 이상 번거롭게 약 이름을 입력할 필요 없이, 빠르고 정확하게 약을 관리하세요!!

### 편리한 알림 설정으로 놓치지 마세요!!

- 아침, 점심, 저녁 복용 시간에 맞춰 정해진 시간에 자동으로 알림을 받으세요.
- 정해진 시간에 알림을 받고 약 복용을 잊지 않도록 도와드립니다!!

### 기술 스택 
| 범위 |  기술 이름 |
|---|---|
| 글자 인식 | ML Kit |

| 형상 관리 | Git GitHub |
| 아키텍처 | CleanArchitecture |
| 디자인 패턴 | Repository  MVVM |
| 비동기 처리 | Coroutine  StatusFlow |
| 지도 | KakaoMap |
